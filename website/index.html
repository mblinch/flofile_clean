For professional sports photographers

Caption the game as fast as you shoot it.

FloFile Captions is a desktop and mobile app for professional sports photographers that writes and checks photo captions and IPTC metadata. Use roster-based player codes (for example h34 = home #34, v34 = visitor #34), caption templates, code replacement, caption verification, ingest-folder watching, and FTP transmit.

Features

Built for the sideline workflow.

Less retyping. Cleaner metadata. Captions that match how sports photographers actually work between periods and on deadline.

Codes

Roster-based player codes

Drop codes such as h34 or v34 into a caption and FloFile fills the matching home or visitor player from the roster.

Templates

Caption templates

Keep house style and client specs in reusable templates so every frame starts from the right structure.

Replacement

Code replacement

Replace structured codes from rosters, verbs, and game state as you work — without rewriting the sentence for every frame.

Verification

Caption verification

Check captions before you send so names, numbers, and game context stay consistent under deadline.

Ingest

Folder watching

Watch an ingest folder so new frames are ready to caption as they land on disk.

Transmit

FTP transmit

Send captioned files to the destination you configure. You enter the credentials; FloFile does not claim affiliation with any wire service, league, or team.

Why FloFile

Built by a working sports photographer.

FloFile Captions comes from nights when the final horn sounds and the captions still have to go out — where accuracy and speed both matter.

We don’t use AI facial recognition. FloFile keeps you in control with roster picks, structured captions, and verification instead.
