Features

Built for the sideline workflow.

Less retyping. Cleaner metadata. Captions that match how sports photographers actually work between periods and on the wire.

Controls

Player, verb, game state

Select names and action from structured controls instead of rewriting the same sentence for every frame on deadline.

Live preview

Captions as you choose

Watch the caption update as you change players, verbs, and inning or period — then write it when the line is right.

IPTC

Read and write metadata

Read existing IPTC fields and write captions back into your files so delivery pipelines stay consistent from laptop to desk.

Codes

Built-in code replacements

Drop structured codes into your caption formulas and FloFile fills them from the roster, verbs, and game state as you work.

Outlets

Getty, Imagn, and AP setups

Start from caption layouts tuned for Getty, Imagn, and AP — or build your own custom caption setups for house style and client specs.

Rosters

Paste rosters from the web

Copy a roster from a team or league site and paste it in. FloFile picks up the names and numbers so you can caption without retyping the list.

Why FloFile

Built by a working sports photographer.

FloFile Captions comes from nights when the final horn sounds and the captions still have to go out — for NHL, MLB, and international events where accuracy and speed both matter.

We don’t use AI facial recognition. It’s expensive, and you still end up confirming every face yourself — so FloFile keeps you in control with roster picks and structured captions instead.

We’re based in Toronto. Learn more on our About page, or contact us about early access.
